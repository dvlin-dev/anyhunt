# Scraper

将 URL 转换为结构化内容的内部浏览器采集引擎，通过受控 Agent Tool 提供能力。

## 职责

- 通过共享 Playwright 浏览器池渲染页面。
- 提取可读 Markdown、HTML、链接与元数据。
- 应用页面配置、等待策略与有界浏览器动作。

## 约束

- 每个目标都必须通过共享 SSRF Guard；浏览器池也要阻止不安全子请求。
- 浏览器并发与页面上限来自配置；每条失败路径都必须释放页面与队列资源。
- 采集使用明确的服务级并发、超时和响应大小上限，不依赖会员、余额或按次扣费。
- Scraper 不暴露产品 API、不持久化采集任务，也不承担截图、PDF 或对象存储职责。
- 请求 Header 只在本轮运行时使用，不得写入 Run、日志或检查点。
